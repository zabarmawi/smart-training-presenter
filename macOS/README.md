# macOS — 0.6.1 Build 13

إعداد: فهد عبدالله زبرماوي

المصدر مشترك لمعالجات Intel وApple Silicon. «الإعدادات ← حول التطبيق» يعرض الإصدار والبناء من Info.plist، والعبارة أعلاه. المصدر مشتق من مرجع Intel Build 12؛ لم يتغير محرك المؤقت.

```sh
PRESENTER_ARCH=x86_64 bash scripts/build.sh --dmg
PRESENTER_ARCH=arm64 bash scripts/build.sh --dmg
```

الحزم التجريبية لا تتضمن الكتالوج المرجعي الخاص أو الحقائب أو الاعتمادات. استعادة المكتبة مستقلة؛ تثبيت التطبيق وحده على جهاز جديد لن يُظهر الحقائب تلقائيًا. راجع README في جذر المستودع وTools/README.md. بعض اختبارات التكامل القديمة تحتاج عينات خاصة غير مضمنة؛ لا تمثل جزءًا من اختبار تلقائي عام مكتمل.

تشغيل ARM64 على جهاز Apple Silicon فعلي غير مختبر. التوقيع محلي ad-hoc وليس Developer ID أو توثيق Apple. راجع RELEASE-NOTES.md للحدود.

## المكتبة المرافقة المعتمدة للتوزيع

نزّل SmartTrainingPresenter-TrainingLibrary-11Bags-v1.zip لإضافة الحقائب الإحدى عشرة الجاهزة بأزمنتها وروابطها واعتماداتها. في Windows استخدم استيراد المكتبة المعتمدة؛ في Mac أغلق التطبيق ثم افتح «إضافة المكتبة على Mac.command» من الحزمة المرافقة. لا تتضمن المكتبة المرافقة ملف المستخدم الشخصي أو استعادة جلسته.
