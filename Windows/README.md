# Smart Training Presenter — Windows x64 Build 16 — Pointer candidate

المصدر المصحح 0.6.1.16. يتطلب Windows x64 و.NET Desktop Runtime 10 x64. عارض PDF الافتراضي Windows.Data.Pdf مع NativePdf.exe المرفق؛ لا يعتمد على مجلد Codex أو Poppler. تحويل PowerPoint اختياري ولم يُختبر.

للبناء باستخدام .NET SDK 10 ومترجم Framework64 في Windows:

```powershell
.\build.ps1 -Destination C:\YourWorkspace\NewBuildFolder
```

البناء دون مصادر NuGet خارجية. المثبت يتحقق من SHA-256 ويرفض المجلد غير الفارغ، وينشئ اختصار قائمة ابدأ دون معاملات اختبار. المكتبة الخاصة غير مضمّنة؛ PDF المضمّن عينة صناعية فقط.

مسار التشغيل العادي ثابت: %LOCALAPPDATA%\SmartTrainingPresenter\UserData. يحفظ ActiveLibrary.json جذر المكتبة. الحالة الموجودة لها الأولوية؛ يُشار إلى مكتبة Build14 عند غياب الحالة الجديدة دون استبدال قراراتها. الاستعادة من ملف ← استعادة المكتبة المعتمدة؛ اختر PORTABLE-APPROVED-LIBRARY أو الحزمة المحتوية عليه. تُنشأ وجهة مستقلة وتُفحص البصمات والمعرّفات. لا يعاد استخراج الأنشطة أو اعتمادها.

المراجعة منفصلة عن العرض، والملفات قابلة للإخفاء، والمكتبة تميز المسار والمجال والحقيبة. المؤقت مصغر أو ثابت أو مخفي. Countdown.cs مطابق لـBuild14؛ مرجع Mac لم يُعدّل.

للاختبار المعزول فقط: --profile <new-folder>. فحص المؤقت: --timer-vectors <inputs.json> <output.json>. فحص التطبيق: --acceptance <portable> <new-profile> <report.json>. التشغيل العادي لا يحتاج معاملات. راجع تقرير B15 لنتائج الاختبار اليدوي وحدوده.

## المكتبة عند التثبيت على جهاز جديد

**المكتبة تُستعاد منفصلة؛ تثبيت التطبيق وحده على جهاز جديد لن يُظهر الحقائب تلقائيًا.**

استعدها من «ملف ← استعادة المكتبة المعتمدة»، باستخدام الحزمة الخاصة. احتفظ بنسخة احتياطية من بياناتك قبل الاستعادة، وتحقق من إعادة الفتح. لا ترفع ملف المستخدم الشخصي أو استعادة جلسته. المكتبة المرافقة المصرح بتوزيعها تُرفق كأصل تنزيل مستقل، خارج مستودع المصدر.

## المكتبة المرافقة المعتمدة للتوزيع

نزّل SmartTrainingPresenter-TrainingLibrary-11Bags-v1.zip لإضافة الحقائب الإحدى عشرة الجاهزة بأزمنتها وروابطها واعتماداتها. في Windows استخدم استعادة المكتبة المعتمدة؛ في Mac أغلق التطبيق ثم افتح «إضافة المكتبة على Mac.command» من الحزمة المرافقة. لا تتضمن المكتبة المرافقة ملف المستخدم الشخصي أو استعادة جلسته.

## تصحيح البوينتر B16

PageDown/PageUp في المدرب والجمهور ولوحة المدرب. الأسهم والمسافة وBackspace تنقل عند تركيز الشريحة؛ التحرير والحوارات والمصادر الخاصة تحتفظ بإدخالها. أول WM_KEYDOWN فقط ينتقل، وتُستهلك رسائل التكرار حتى حدود الصفحات. المفاتيح المعدّلة لا يلتقطها المستقبل الجديد؛ تبقى اختصارات B15 السابقة.

اختبار الإصلاح فقط:

```powershell
.\SmartTrainingPresenter.exe --pointer-acceptance C:\Fixture\pointer.stpresenter C:\NEW-profile C:\pointer-results.json
```

يتطلب سطح مكتب Windows تفاعليًا وخاملًا أثناء الاختبار، ومشروعًا اصطناعيًا بست صفحات عرض على الأقل ومادة مصدر خاص. الاختبار ينسخ المشروع فقط إلى ملف جديد؛ لا يستورد مكتبة أو يفهرسها. SendKeys يختبر ضغطات Windows، وPostMessage يختبر بت التكرار. لا يثبت ذلك سلوك جهاز HID مادي. المثبت ينشئ Smart Training Presenter B16.lnk مستقلًا عن B15. المصدر النهائي والاختبارات المطابقة وحدود التحقق في WINDOWS-B16-POINTER-FIX-REPORT.md.
